# 管理组使用说明

> 给社长、部长们的操作手册。后台地址：**https://hhxyjwsyst.online/admin**（手机微信里直接打开）。
> 账号密码找网站管理员领取；忘记密码也找管理员重置。

## 先记住一件事

**任何修改保存后，约 3 分钟才会在网站上生效**（系统在后台自动重新发布）。看到「已提交发布」的提示就可以关闭页面了，不用一直等。页面会在发布完成时提示「已上线」。

---

## 一、换微信群二维码（最常用，一分钟）

微信群二维码约 7 天过期，过期前进群的人会扫不出来，**请每周固定换一次**。

1. 微信里打开纳新群 → 点右上角「…」→ 群二维码 → 截图（只要码本体，裁成接近方形）；
2. 打开后台 → 底部「二维码」→ 点「微信群 · 纳新群」卡片的 **上传新码** → 选刚截的图；
3. 看到「新码已提交」提示即完成。顺手把「群码过期日」改成新码的过期日期，概览页就会显示倒计时提醒。

> QQ 群、公众号、抖音的码长期有效，一般不用动；要换也是在同一页操作。

## 二、更换橱窗内容（半学期一次的大更新）

打开底部「橱窗内容」，顶部下拉切换分区：

| 分区 | 能做什么 |
| --- | --- |
| 作品位 | 替换图片、改说明文字、删除、添加新作品位 |
| 四季 | 换图、改季节名称和描述 |
| 首屏轮播 | 换图、删除、新增（第 1 张是首屏大图，**请压到 500KB 以内**再传） |
| 文案 | 主 Slogan、社团介绍、微信号、邮箱 |
| 背书证书 | 官方背书的标题/描述、证书图片 |
| 关于与短片 | 「关于我们」配图、精选短片及其封面 |

**换图五步**：选分区 → 点该条目的「替换图片」→ 选照片 → 看到「已提交」→ 点右下角 **保存并发布**。

注意事项：
- 图片请先压到 **2MB 以内**（超过会直接被拒绝）；
- 黄色「有未保存修改」亮着时，说明改了还没保存，此时退出页面会丢改动；
- 作品说明默认不写同学姓名（保护隐私），确需署名请在说明末尾加「· 姓名 摄」。

## 三、改错了怎么办：回滚

底部「发布历史」列出每一次修改（谁、什么时候、改了什么）。点某条记录的 **回滚**，全部内容会恢复到那次修改时的样子，约 3 分钟生效。**所有版本永久保留，随便试，改不坏。**

## 四、发布记录里的名字

每条记录的作者是登录账号。请用自己的账号登录，不要借用别人的。

## 五、遇到问题

| 现象 | 处理 |
| --- | --- |
| 登录提示「尝试次数过多」 | 密码连错 5 次会锁 10 分钟，等一会儿再试 |
| 保存后 10 分钟网站还没变 | 可能发布失败，联系网站管理员 |
| 提示「刚有人保存过，请刷新」 | 两个人同时改了同一处，刷新页面重新改一次 |
| 后台完全打不开 | 联系网站管理员（会走 GitHub 直接改的兜底路径） |
