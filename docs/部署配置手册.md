# 部署配置手册（给网站管理员）

> 一次性配置约 20 分钟。之后日常零维护，只有两项年度提醒（见文末）。

## 1. 前提确认

- Vercel 项目已通过 Git 集成连接本仓库（Settings → Git → Connected Git Repository 指向 `AdgaiWalker/jiaowai-shuying-landing`）。**push 到 main 自动构建**，`api/*.js` 会自动作为 Serverless Functions 部署；
- 若当前项目是"直接上传 dist"方式创建的，需要重新用 Git 集成方式导入（否则函数不会部署、推送也不触发构建）。

## 2. 创建 GitHub 机器人令牌（PAT）

1. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token；
2. Repository access：**Only select repositories** → 选 `jiaowai-shuying-landing`；
3. Permissions → Repository permissions → **Contents: Read and write**（其余一律 No access）；
4. Expiration：**1 年**（自定义到期日，记入日历，见 §6）；
5. 生成后立即复制 token（只显示一次）。

## 3. 配置环境变量（Vercel → Settings → Environment Variables）

| 变量 | 值 | 说明 |
| --- | --- | --- |
| `ADMIN_ACCOUNTS` | `{"miaomiao":"密码","shezhang":"密码","zhouhongxu":"密码","wuchangxuan":"密码"}` | 每人一个账号（key 用英文，发布记录显示它）；改完**立即生效**，无需重新部署 |
| `ADMIN_SECRET` | `openssl rand -base64 32` 的输出 | Cookie 签名密钥，泄露需轮换（轮换 = 换值后所有人重新登录） |
| `GITHUB_TOKEN` | §2 生成的 PAT | 机器人写仓库的身份 |
| `GITHUB_REPO` | `AdgaiWalker/jiaowai-shuying-landing` | 可选（已有默认值） |
| `GITHUB_BRANCH` | `main` | 可选（已有默认值） |
| `STORAGE_ADAPTER` | 不填 | 预留：`github`（默认）/ `local`（NAS 迁移演练用） |

> 生产/预览两个环境都配（Environment 选 All）。

## 4. 上线顺序

1. 合并 `feat/admin` → `main`（**不提交 dist/**，Vercel 自行构建）；
2. 等 Vercel 部署完成（Deployment 状态 Ready）；
3. 验收清单（PRD §9）：
   - 手机微信打开 `https://hhxyjwsyst.online/admin` → 登录；
   - 上传一张测试群码 → ≤10 分钟后前台扫码区变化；
   - 改一条作品说明 → 保存 → 前台生效；
   - 发布历史 → 回滚刚才的改动 → 前台恢复；
   - 制造字段缺失（改坏 JSON 再改回）验证前台不白屏（本地已验证 EB-1，线上抽查即可）；
   - 非管理组账号（无 ADMIN_ACCOUNTS 中的账号）无法登录。
4. 把《管理组使用说明》发到管理组群，附上各自账号密码（私发）。

## 5. 日常运维

| 事项 | 操作 |
| --- | --- |
| 新增/删除管理员、改密码 | 改 `ADMIN_ACCOUNTS` 环境变量 → Save（立即生效） |
| 人员毕业交接 | 删旧账号 + 加新账号 + 交接《使用说明》与本手册 |
| 后台故障（登录异常/保存报错） | 兜底路径：管理员直接在 GitHub 网页/App 编辑 `src/content/*.json` 或替换 `public/qr/*.jpg`，提交即自动部署 |
| 疑似 Token 失效（保存报 500 且信息含 401） | 重新生成 PAT → 更新 `GITHUB_TOKEN` |
| 群码临期自动提醒 | 每日 10 点 `qr-expiry-watch` 巡检：剩 ≤3 天自动开 Issue（邮件通知仓库 Watch 者），换码后自动关闭——**管理员需在仓库点一次 Watch → Watching** |
| 构建/部署日志 | Vercel Dashboard → Deployments |

## 6. 年度提醒（建议现在就设日历）

- [ ] **PAT 续期/重建**：到期前 1 个月 GitHub 会发邮件提醒；换新 token 后更新环境变量；
- [ ] **ADMIN_SECRET 轮换**（可选，每年一次）：换值后所有会话失效，成员需重新登录。

## 7. 故障对照（PRD EB 表的排查入口）

| 现象 | 对应机制 | 自查 |
| --- | --- | --- |
| 前台某区块内容异常/变默认 | EB-1 逐字段兜底 | 查最近提交改了哪个 JSON，回滚 |
| 图片位置空白占位框 | EB-2 路径 404 | 查 JSON 里 src 路径与 public/ 文件名是否一致 |
| 保存后 10 分钟未生效 | EB-3 构建失败 | Vercel Deployments 看报错（常见：JSON 语法错误） |
| 后台整站打不开 | EB-4 | 用 GitHub 直改兜底；查 Vercel 状态页 |
| 改坏了想撤 | EB-5 | 后台「发布历史」回滚，或 GitHub revert |
| 上传超大图被拒 | EB-6 | 压到 2MB 内再传 |
| 首屏变慢 | EB-7 | 检查 hero 第 1 张是否超 500KB，回滚或换小图 |
